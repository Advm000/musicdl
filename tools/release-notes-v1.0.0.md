## 🎵 Music DL v1.0.0 — première version

**Installation** : télécharge `Music-DL-Setup.exe` ci-dessous et lance-le. Aucune autre dépendance.

### Fonctionnalités
- 🔍 **Recherche YouTube Music** — chansons avec artiste, album, durée et pochettes officielles (ou colle un lien YouTube)
- ⬇️ **Téléchargement MP3 / M4A** — 128, 192 ou 320 kbps, jusqu'à 3 en parallèle, progression en direct
- 🖼️ **Vraies pochettes d'album** intégrées dans chaque fichier et affichées dans l'app
- 📂 **Dossier automatique** `Musique\Music DL`
- ✈️ **Mode hors ligne** — bibliothèque, playlists et lecture sans internet
- 🎧 **Lecteur intégré** — grand lecteur, file d'attente, aléatoire, répétition, favoris, touches média
- 🔄 **Mises à jour automatiques** — notification + installation en un clic dans l'app

> ⚠️ Windows peut afficher un avertissement SmartScreen (application non signée) : clique sur **« Informations complémentaires » → « Exécuter quand même »**.
